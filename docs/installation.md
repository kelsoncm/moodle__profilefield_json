# Instalação — moodle-profilefield_json

## Passo a Passo de Instalação

1. Acesse o diretório de campos de perfil do Moodle:
   ```bash
   cd /caminho/do/moodle/user/profile/field
   ```
2. Clone o repositório nomeando a pasta como `json`:
   ```bash
   git clone https://github.com/moodle-by-kelsoncm/moodle-profilefield_json.git json
   ```
3. Acesse **Administração do site → Notificações** para concluir a atualização no banco de dados.
