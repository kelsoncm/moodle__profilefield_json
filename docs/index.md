# Visão Geral — moodle-profilefield_json

O **`moodle-profilefield_json`** é um plugin de campo de perfil de usuário personalizado que permite armazenar, visualizar e editar dados no formato **JSON** com rich editor ([JSONEditor](https://github.com/josdejong/jsoneditor)) e validação por **JSON Schema**.

---

## 🚀 Principais Recursos

- **Visualização & Edição Interativa**: Utiliza o JSON Editor/Viewer para edição intuitiva em árvore ou código.
- **Validação com JSON Schema**: Garante a integridade dos dados inseridos no perfil do usuário de acordo com o esquema definido.
- **Formato Padrão UTF-8**: Facilita processos de integração com APIs e sistemas legados.
